# RackCraft sample stencils

These two `.vssx` files are hand-authored, deterministic fixtures with the same
OPC/ZIP and Visio 2013 XML structure as vendor stencil libraries. They are not
copied from any commercial stencil set.

| File | Masters |
| --- | --- |
| `rackcraft-datacenter.vssx` | 25U open frame rack, 24-port CAT6 patch panel, 24-port gigabit switch, 1U cable manager |
| `rackcraft-modular.vssx` | 24-aperture modular patch panel, CAT6 keystone jack RJ45 |

Each master includes:

- vector geometry (rectangles and lines, Visio Y-up coordinates);
- `Connection` rows used by RackCraft's magnetic snapping;
- `Property` shape data for manufacturer, part number and description;
- a 32×32 ICO preview decoded by the stencil browser;
- category, rack-unit and mounting metadata where relevant.

## Regenerate

```bash
python3 tools/generate_samples.py
```

The script requires Python 3.10+ and the standard library. ZIP entry timestamps
and contents are fixed, so regenerating the fixtures produces byte-identical
packages. The resulting stencils are licensed like the rest of RackCraft:
MIT OR Apache-2.0.

## Use

- In the app, the bundled copies are available immediately from the stencil
  browser; **Import .vssx** loads any external library.
- In tests, `rackcraft_io::BUNDLED_STENCILS` feeds the parser without disk or
  network access.
- The built-in `--sample` document is generated by `rackcraft-engine` so it
  remains editable even if a stencil library is unavailable.
